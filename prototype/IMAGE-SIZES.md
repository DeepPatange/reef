# Image sizes for the website

The site uses 62 photos, and each one is one of four shapes. Generate each photo at the size shown. If your tool's output is smaller, create the image in the same shape at the largest size available, then upscale it 2×.

| Shape | Generate at | Minimum | How many |
|---|---|---|---|
| **Wide 16:9** | 3840 × 2160 | 2560 × 1440 | 5 |
| **Landscape 4:3** | 2400 × 1800 | 1600 × 1200 | 14 |
| **Square 1:1** | 2048 × 2048 | 1440 × 1440 | 7 |
| **Portrait 4:5** | 1600 × 2000 | 1280 × 1600 | 36 |

Save them in `assets/img/` with the file names below as JPG. Claude will make the smaller web copies and swap them in.

Do not put any text, logos or labels in the images. The site adds those.
